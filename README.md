# GC Intelligence · GottCured

Dashboard inteligente de gestão clínica e laboratorial com:

- Previsão de demanda e absenteísmo
- Alertas preditivos de equipamentos e processos
- Visão por setores (Clínica e Laboratório)
- Simulações e insights operacionais

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React (ícones)
- Recharts (gráficos)

## Como rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Estrutura

```
src/
  App.tsx          # Aplicação principal (dashboard completo)
  index.css        # Estilos + Tailwind + tema
  main.tsx         # Entry point
  assets/          # Logo e imagens
```
